# BeefNoodle

牛肉面数值计算脚本语言。

> 写工程计算、试验数据处理、公式推导
> 写完直接编译成不依赖任何东西的 exe，拷到别的电脑上双击就能跑。

查看版本
beefnoodle.exe version

运行脚本
beefnoodle.exe run hello.bn

## 环境要求
- Windows（x86-64）
- 无需额外运行时，解压即用

## 项目结构
beefnoodle.exe       主程序

beef.exe             别名

文档\        

编辑器插件\          VS Code 插件（.vsix）
