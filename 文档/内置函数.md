# BeefNoodle 内置函数总表

共 **197** 个内置函数。三种查法：

```beefnoodle
help                 // 交互模式里：列出全部
help readfile        // 交互模式里：查单个
```

```powershell
beef funcs           # 命令行：列出全部
beef help readfile   # 命令行：查单个
```

格式说明：`名字` 后面是**用法 + 说明**。缺省写法（如 `size(A)`）里 `m`/`v`/`s` 分别
指矩阵、向量/矩阵、字符串；带 `...` 的是可变参数。
