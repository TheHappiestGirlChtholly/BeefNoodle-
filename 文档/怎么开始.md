# BeefNoodle —— 怎么开始



1. 新建一个文本文件，改名成 `hello.bn`，里面写：

```beefnoodle
// 第一个程序
x = linspace(0, 1, 5);
print(x);
print(mean(x));
```

2. 在这个文件所在目录打开 PowerShell，运行：

```powershell
.\beefnoodle.exe run hello.bn
```

3. 看到输出就成功了。想变成能双击的独立程序：

```powershell
.\beefnoodle.exe build hello.bn
.\hello.exe
```
